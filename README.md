# Sarah Nexus

**Intelligent computer diagnostics — designed to make troubleshooting easier.**

Sarah Nexus is a computer diagnostics project focused on helping people identify system issues, understand what they mean, and work toward safe solutions.

## What is Sarah Nexus?

Sarah Nexus aims to provide a clear, guided experience for computer diagnostics, without requiring users to understand complex technical details.

The project's broader goals include:

- **System diagnostics** — identify relevant hardware and system information.
- **Clear explanations** — present findings in understandable language.
- **AI-assisted analysis** — help interpret diagnostic results.
- **Safer troubleshooting** — guide users through appropriate next steps.

> **Development status:** Sarah Nexus is under active development. The features above describe the project's direction, not a guarantee that every feature is available in this prototype.

## Download and installation

There is **no public, installable Sarah Nexus release in this repository yet**.

When a verified release is available, it will be listed under [Releases](../../releases) with its installation instructions. Until then, please do not treat the source code in this repository as a finished installer or a bootable USB image.

## Current prototype

This repository currently contains an early, **read-only** diagnostics prototype. It can report basic CPU and memory information and is intended for development and evaluation rather than everyday end-user installation.

It does **not** repair devices, assess hardware health, or provide a bootable Sarah Nexus system.
