# Sarah Nexus — Prototype Repository

This repository is reserved for a future independently runnable, validated Sarah Nexus prototype.

## Current status

**No active prototype implementation is present in this repository.** The earlier browser-based Cloudflare Workers AI demonstration was removed because it did not meet the project's expectations. Do not present the former demo as a supported or validated Sarah Nexus build.

The real Sarah Nexus product is developed separately in the private `Dev2024-prog/Sarah-Nexus` repository. This public repository remains available for a future deliberately reviewed prototype release.

## Release requirements

See [`docs/release-policy.md`](docs/release-policy.md) for source identity, verification, build and publication requirements. A future prototype must be independently runnable and accurately describe its capabilities.

## Deployment notice

Removing source and deployment configuration from GitHub **does not automatically undeploy** any previously published Cloudflare Worker. The old Worker must be disabled or deleted separately in Cloudflare to prevent public access.
